# Отчёт: концепт-сайт «Погреб»

Одностраничный сайт вымышленного винного бара с винотекой в сводчатом подвале. Чистые HTML + CSS + JS, без сборщиков. Анимации на GSAP 3.12.5 + ScrollTrigger (файлы в `/vendor`). Шрифты Google Fonts лежат в репозитории: Prata, Golos Text, Cormorant Italic.

## Что сделано по секциям

1. **Экран 18+.** Тёмный «подвальный» экран с вопросом «Вам есть 18 лет?», кнопки «Да» и «Нет». «Да» запоминается в localStorage, «Нет» — на сутки, плюс вежливая заглушка с кнопкой «Я ошибся с ответом». Пока экран открыт, остальная страница `inert`.
2. **Шапка.** Свой логотип: арка свода и бокал внутри. Бокал в логотипе — индикатор прочитанного: наполняется по мере прокрутки. Меню из 5 пунктов подсвечивает текущий раздел; кнопка «Забронировать стол»; на телефоне бургер с полноэкранным меню.
3. **Hero.** Заголовок «Вино под ваш вкус, а не под этикетку», подзаголовок, кнопки «Подобрать вино» и «Забронировать», четыре факта (−6 м, +14 °C, 19 вин, 34 места) и большой SVG-бокал.
4. **Подбор вина + колесо ароматов.** Три ползунка, фильтр цвета, 19 карточек-«бирок» с аркой сверху, как бирки на бутылках в погребе. Пустое состояние «Под такой вкус ничего нет — сдвиньте ползунок».
5. **Карта вин** (пункт меню «Карта»). Статичный список в духе меню бара: цена за бокал 125 мл и за бутылку в зале, табличные цифры. Работает и без JavaScript. Рядом — предупреждение о вреде и «18+».
6. **Винные ужины.** Ближайшие 6 вечеров (четверги и субботы, считаются от сегодняшней даты): тема, сет из 5 бокалов и закуски, цена, «осталось N мест». «Записаться» открывает `<dialog>` с выбранной датой. После записи число мест уменьшается.
7. **Сомелье.** Лидия Жаворонкова (вымышленная): бывший геолог, короткий рассказ, цитата. Блок «3 вина, которые я бы взяла сегодня»: ссылка ставит ползунки на вкус вина, и его карточка встаёт первой. Вместо фото — иллюстрация (арка, монограмма, блокнот дегустатора): без людей и без алкоголя в кадре.
8. **Зал.** SVG-иллюстрация: три кирпичные арки, стеллаж с бутылками, столы, мерцающие свечи (CSS-анимация пламени и ореола). Под ней три факта: 9 столов на 34 места, уютно на 2–8 человек; длинный стол на 12; +21 °C в зале.
9. **Бронь стола.** Дата, гости (степпер 1–8), слоты времени (занятые зачёркнуты), имя, телефон, пожелания со счётчиком. Проверка полей, демо-подтверждение «Бронь принята (демо)» со сводкой.
10. **Подвал.** Адрес-заглушка, часы работы, крупное предупреждение о вреде, знак 18+, плашка «Концепт-проект. Бренд вымышленный. Дизайн и разработка — ViachKovDesign» со ссылкой.

## Как работает перетекание цвета

- У каждой секции есть атрибут `data-tone`: straw → pale → blush → rose → garnet → bordo → deep → cellar.
- Один ScrollTrigger на всю страницу на каждом кадре прокрутки находит секцию под линией 55% экрана. В последних 45% её высоты цвет плавно смешивается со следующим тоном (смешивание в OKLab, сглаживание smoothstep).
- Для получившегося фона функция `palette()` из `js/color.js` подбирает весь набор переменных: `--bg`, `--ink`, `--muted`, `--line`, `--line-strong`, `--surface`, `--wine`. Текст не интерполируется, а выбирается так, чтобы контраст был не ниже 4.6:1; на «мёртвой» середине пути между светлым и тёмным чернила уходят к чистому чёрному или белому. Карточки сдвигаются от цвета чернил, поэтому на них контраст только выше.
- Проверка: перебор 1400 промежуточных фонов — худший контраст текста **4.60:1**, рамок полей **3.10:1**. axe-core в 25 точках прокрутки нарушений контраста не нашёл.
- Без JS и при `prefers-reduced-motion` секции получают свои статичные тоны: те же цвета, сгенерированные в CSS (`node tools/sync.mjs`).
- Бокал: волна — SVG-путь, который пересчитывается в `requestAnimationFrame`, скорость прокрутки раскачивает её. Пока первый экран уезжает, уровень поднимается, а цвет идёт от соломенного к гранатовому. Анимация на паузе, когда бокал не виден.

## Как работает подбор

- Вкус вина — точка в трёх осях от 0 до 10: сладость, плотность, мягкость. Близость — евклидово расстояние до точки, заданной ползунками. Показываются вина на расстоянии ≤ 4.5, остальные скрываются; процент совпадения на карточке = 1 − расстояние / максимум.
- Перестановка — FLIP на Web Animations API: запоминаем позиции, меняем порядок в DOM, анимируем от старого места к новому. Новые карточки проявляются.
- На шкалах карточки две отметки: заливка — вино, кружок — ваш вкус. У ползунков — нативные `input range` с подписями значений («полусухое») и `aria-valuetext`.

## Как работает колесо ароматов

- SVG из 8 секторов: фрукты, ягоды, цветы, травы, специи, дерево, земля и камень, выпечка и орехи. В центре — число вин с выбранным ароматом.
- Наведение — предпросмотр, клик или Enter — закрепить, повторный клик или Esc — снять. Клавиатура: одна точка табуляции, стрелки ходят по кругу, Home/End.
- Подходящие карточки получают сплошную рамку и бирку с названием аромата, остальные — пунктир. Под колесом — список всех вин с этим ароматом ссылками; ссылка показывает вино в подборе.

## Проверки

- **Автотесты** (`node tools/shoot.mjs`), все проходят:
  - нет горизонтального скролла на 360 / 375 / 768 / 1280 / 1920;
  - после прокрутки не остаётся невидимых блоков;
  - ноль ошибок и предупреждений в консоли, ноль упавших запросов;
  - 18+: закрывается и сохраняет выбор;
  - подбор: после сдвига ползунков порядок меняется, ползунок слушается клавиатуры, пустое состояние появляется;
  - колесо: подсвечивает карточки и работает со стрелок и Enter;
  - ссылка сомелье выводит вино первым;
  - формы: пустые не проходят, заполненные показывают подтверждение, места на ужин уменьшаются;
  - reduced-motion: перетекание выключено, всё видно;
  - без JS: карта вин читается.
- **Доступность:** axe-core на всей странице (десктоп, телефон, reduced-motion) — 0 нарушений. Контраст при перетекании — 0 нарушений в 25 точках. Один `h1`, видимый фокус, `label` у всех полей, зоны касания ≥ 44 px.
- **file://** — открывается двойным щелчком, ошибок в консоли нет.

## Самопроверка на шаблонность

- Кремовый фон с терракотой: нет, фон меняется от соломенного к почти чёрному.
- Фиолетовые градиенты: нет.
- Эмодзи-иконки: нет, вся графика — свой SVG.
- Всё по центру: нет, вёрстка асимметричная — номер раздела слева, заголовок справа, ужины в виде ведомости, бронь в две колонки.
- Одинаковые карточки: карточки есть только у вин, и там они по смыслу; ужины — список-ведомость, сомелье — редакционная вёрстка, карта — меню.
- Сквозной мотив — арка свода: логотип, экран 18+, бирки вин, портрет сомелье, иллюстрация зала, рамка формы.

## Что упрощено и почему

- **GSAP и шрифты лежат в репозитории, а не на CDN** — cdnjs недоступен из среды разработки; заодно сайт работает офлайн.
- **Без Lenis** — нативная прокрутка надёжнее на телефонах.
- **Занятость слотов вымышлена** (хэш от даты) — бэкенда нет.
- **Даты ужинов считаются от текущей даты** — концепт не устаревает.
- **CSS и JS не минифицированы** — это портфолио, код должен читаться; на GitHub Pages файлы сжимаются gzip.
- **Поле даты нативное** — на скриншотах безголовый Chromium показывает «mm/dd/yyyy», у русскоязычного пользователя будет «дд.мм.гггг».
- **Полные скриншоты страницы сняты со статичными тонами:** на одном снимке перетекание не показать, для него есть серия `flow-*`.

## Идеи улучшения

1. Режим «Сравнить два вина»: две карточки рядом, наложенные шкалы вкуса.
2. «Вкусовой профиль» в URL (`?s=2&b=5&f=5&c=red`), чтобы подборкой можно было поделиться.
3. Звук зала по желанию (тихий гул разговоров и потрескивание свечи) с явной кнопкой включения.
4. Вид карты вин «для печати»: отдельный CSS, чтобы распечатать меню бара на A4.
5. Мини-квиз из 4 вопросов («что вы любите на завтрак?») вместо ползунков — для тех, кому неудобно думать категориями «плотное/свежее».
6. Тёмная тема для тех, кто открывает сайт ночью: сразу тон «подвала» с перетеканием в обратную сторону.
7. Анимация пузырьков в бокале, когда в фильтре выбрано игристое.
8. Схема зала в бронировании: выбрать нишу или стол под аркой прямо на иллюстрации.
9. Английская версия с переключателем языка.
10. Перевести иллюстрацию зала на `<canvas>` с мягким светом от свечей, реагирующим на курсор.

## Как открыть и опубликовать

**Локально.** Двойной щелчок по `index.html` или:

```bash
python3 -m http.server 8000
```

затем открыть `http://localhost:8000/`.

**GitHub Pages:**

1. Влить ветку в `main`.
2. Открыть **Settings → Pages**.
3. Выбрать **Deploy from a branch → main → / (root) → Save**.
4. Через 1–3 минуты появится ссылка `https://viachkovdesign.github.io/pogreb-concept/`.

Подробно — в README.md. Сайт не публиковался: GitHub Pages не включён.
