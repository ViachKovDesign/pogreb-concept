# Погреб — концепт сайта винного бара

Концепт-проект для портфолио веб-дизайнера **ViachKovDesign**. «Погреб» — вымышленный винный бар с винотекой в старом сводчатом подвале в Москве. Бренд, люди, адрес и вина выдуманы; сорта винограда и регионы настоящие.

Главное на сайте:

- **цвет страницы перетекает при прокрутке**, как вино в бокале: соломенное «белое» → «розе» → гранатовое «красное» → почти чёрный подвал. Текст на каждом промежуточном цвете остаётся контрастным;
- **бокал на первом экране**: вино колышется, а уровень и цвет меняются, пока вы листаете;
- **подбор вина по вкусу**: три ползунка и фильтр цвета, карточки на лету перестраиваются по близости к вашему вкусу;
- **колесо ароматов**: наведите или нажмите на сектор — подсветятся вина с этим ароматом;
- **винные ужины, сомелье, зал, бронь стола** — формы с проверкой и демо-подтверждением (ничего никуда не отправляется).

Без онлайн-продаж: только бронь и запись на ужины, экран 18+ и предупреждение о вреде алкоголя.

## Как открыть локально

### Самый простой способ
Скачайте репозиторий (зелёная кнопка **Code → Download ZIP**), распакуйте и дважды щёлкните `index.html`. Сайт откроется в браузере и будет работать: данные вин продублированы прямо в странице.

### Как на настоящем сайте (через локальный сервер)
Нужен установленный Python 3 (на macOS и Linux он обычно уже есть).

1. Откройте терминал в папке проекта.
2. Запустите сервер:

```bash
python3 -m http.server 8000
```

3. Откройте в браузере `http://localhost:8000/`.
4. Остановить сервер — `Ctrl + C` в терминале.

Если установлен Node.js, можно запустить сервер со сжатием, как на GitHub Pages:

```bash
node tools/serve.mjs 8000
```

## Как опубликовать на GitHub Pages (пошагово, для новичка)

1. Откройте репозиторий на github.com.
2. Если работа лежит в отдельной ветке, сначала влейте её в `main`: вкладка **Pull requests → New pull request**, выберите ветку, **Create pull request → Merge**.
3. Перейдите в **Settings** (шестерёнка вверху репозитория) → слева пункт **Pages**.
4. В блоке **Build and deployment** выберите **Source: Deploy from a branch**.
5. В **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.
6. Подождите 1–3 минуты и обновите страницу настроек — вверху появится ссылка вида `https://viachkovdesign.github.io/pogreb-concept/`.
7. Проверьте сайт по ссылке. Если ссылка ведёт на 404 — подождите ещё пару минут: первая публикация бывает медленной.
8. Если репозиторий называется не `pogreb-concept`, поправьте адрес в двух строках `<head>` файла `index.html`: `og:image` и `og:url`, — иначе превью в соцсетях не подтянет картинку.

## Структура

```
index.html          — вся страница (9 секций)
css/style.css       — стили; тоны секций генерируются из js/color.js
js/color.js         — цветовая математика (OKLab, подбор контрастного текста)
js/app.js           — 18+, меню, подбор, колесо ароматов, ужины, формы, перетекание цвета, бокал
data/wines.json     — 19 вымышленных вин
vendor/             — GSAP 3.12.5 и ScrollTrigger
fonts/              — Prata, Golos Text, Cormorant (Google Fonts, лицензия OFL)
img/                — фавиконы и обложка для соцсетей (og.png 1200×630)
tools/              — помощники: синхронизация данных, скриншоты и автотесты, сервер с gzip, генерация обложки
screenshots/        — скриншоты проверок
DECISIONS.md        — журнал решений
REPORT.md           — итоговый отчёт
```

## Для разработки

```bash
node tools/sync.mjs        # после правки data/wines.json или js/color.js: обновит карту вин, инлайн-данные и тоны в CSS
node tools/serve.mjs 8765  # сервер (или python3 -m http.server 8765)
node tools/shoot.mjs       # скриншоты в /screenshots + автотесты подбора, колеса, форм, 18+, reduced-motion, режима без JS
node tools/assets.mjs      # пересобрать og.png и PNG-фавиконы
```

Для `shoot.mjs` и `assets.mjs` нужен Playwright с Chromium.
